## 📌 Sobre o Projeto

Este projeto foi desenvolvido com foco em performance, praticidade e design altamente responsivo (desktop e mobile). O sistema permite o controle de cadastro de clientes e realiza a simulação instantânea de modalidades de empréstimo (Pessoal, Consignado, com Garantia) de acordo com a renda, idade e localização do cliente.

### 🚀 Principais Funcionalidades
- **Autenticação de Usuários:** Sistema completo de login e cadastro com proteção de rotas.
- **Gestão de Clientes (CRUD):** Listagem dinâmica, cadastro e edição de dados cadastrais.
- **Motor de Análise de Crédito:** Algoritmo que calcula a taxa de juros e verifica a elegibilidade de empréstimos com base em regras de negócio predefinidas.
- **Interface Mobile-First & Responsive:** Experiência fluida otimizada para dispositivos móveis e desktops.

---

## 🛠️ Tech Stack & Arquitetura

### **Front-end**
- **Next.js & React:** Renderização ágil e roteamento otimizado.
- **TypeScript:** Tipagem estática para maior segurança e facilidade de manutenção no código.
- **CSS3 / Modules:** Estilização responsiva customizada com CSS Variables.

### **Back-end & Nuvem (Infraestrutura)**
- **API Node.js:** Hospedada no **Render**.
- **Banco de Dados Relacional:** Gerenciado e hospedado na plataforma **Aiven**.
- **Deploy Front-end:** Integrado à **Vercel** com CI/CD automático a cada push no repositório.
